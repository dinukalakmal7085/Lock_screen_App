# Reference and beta scope

Reference: [Liquid Lock Screen: KaLock](https://play.google.com/store/apps/details?id=com.ios.lockscreen.liquid), listing text inspected on 2026-10-23. The page was readable in the cloud; screenshot downloads were blocked by the environment. No source, branding or artwork was copied.

The user prioritized iPhone-style lock screens and testing an improved app before Play Store preparation.

| Listing describes | Luma 1.2.1-beta.1 |
| --- | --- |
| Large customizable clocks and liquid glass styling | Seven native clock styles including the tall Glass XL, Clear/Frosted/Solid finishes, eight colors and adjustable width/composition |
| 30+ theme collections | 41 original presets: nine cinematic scenes and 32 procedural designs; not 41 separate collections |
| Photo personalization and up to four widgets | Private photo import/crop controls; four slots for real battery, calendar, next alarm and a focus phrase |
| Lock-screen customization and hold/swipe switching | Live draft editor, named looks, horizontal switcher opened by holding the face; unlock required while locked |
| Display using optional accessibility access | Full edition uses a system-bound accessibility overlay; disabled by default, explicit disclosure, no content retrieval or automated gestures; actual OEM wake behaviour still requires phone testing |
| Camera and flashlight shortcuts | Camera app after unlock; full edition optional torch permission |
| Notification display | Optional in-memory summaries, hidden titles while locked, update/dismiss handling |
| Stickers and music/volume controls | Not implemented |
| Photo depth | Built-in layered mountains, six authored cinematic subject boundaries and manual transparent PNG foregrounds; no automatic segmentation |

The beta has no fake weather, music state or demo notification cards. A cloud build and simulated tests do not establish feature parity, superiority, installation approval or Play Store readiness. The next evaluation is the user's own phone test.

The user later supplied screenshots showing ocean wildlife, astronauts, sports, architecture, fantasy and glowing abstract scenes with tall translucent clocks. Nine original AI-generated artworks were added in those directions; the source app’s assets were not extracted. The six authored subject boundaries affect built-in artwork only. Studio previews all new looks while retaining its wallpaper-only permission boundary. This artwork update does not resolve the full edition’s reported Play Protect installation block.
